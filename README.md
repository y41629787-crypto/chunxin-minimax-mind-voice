# 春心错认 MiniMax 心声语音 V1.3.0

独立的 SillyTavern 客户端扩展。安装本仓库即可使用语音按钮和设置，无需安装专属服务端插件。用户点击状态卡「未曾说出口」或「耳语情话」旁的按钮后，扩展只读取当前楼层对应的 `<未言>` 或 `<情话>` 内容并发送至 MiniMax 播放。

## 安装

在 SillyTavern 的 **扩展程序 → 安装扩展程序** 中粘贴：

`https://github.com/y41629787-crypto/chunxin-minimax-mind-voice`

安装后启用「春心错认 MiniMax 心声语音」并刷新页面。

## 配置与使用

在扩展设置中填写自己的 MiniMax API Key 和音色 ID，并选择：

- 模型：`speech-2.8-hd`（默认）或 `speech-2.8-turbo`
- 语言：自动识别（`auto`）、普通话（`Chinese`）或粤语（`Chinese,Yue`）
- 语速：0.5×–2.0×，步长 0.1×，默认 1.0×
- 接口地区：国内（默认）或国际；请使用匹配地区的 Key

点击对应栏目旁的按钮，只朗读该字段；再点一次停止。不会自动朗读。缺少或为空的字段不会显示按钮。切换聊天、楼层或栏目会停止前一段播放。

## API Key 与隐私

Key 保存在用户自己的 SillyTavern 扩展设置中，可修改或清除。由于浏览器中的其他脚本或扩展可能读取扩展设置，此方式的隔离性低于服务端密钥管理。请勿在共享或不可信的酒馆实例中使用个人 Key。

扩展只向用户选择的固定 MiniMax 官方地址请求：国内 `https://api.minimaxi.com/v1/t2a_v2`，国际 `https://api.minimax.io/v1/t2a_v2`。Key 通过 Authorization 请求头发送，不写入源码、日志或错误提示。浏览器 CORS 策略可能阻止直连；扩展不通过自建代理绕过限制。

## 缓存、测试与兼容性

音频仅保存在当前浏览器会话内，最多 24 条，刷新后清空。缓存按文本、音色、模型、语言、语速、地区和格式区分。普通聊天 TTS 仍由 SillyTavern 自己处理。

运行 `npm test` 可执行不调用 MiniMax 的 Node 模拟测试。真实音频需要用户配置 Key 后主动点击播放。Windows 浏览器路径已验证；Android/Termux 尚未完成实机验证，且直连可用性取决于浏览器和 MiniMax 的 CORS 响应。

## 版本与回滚

V1.3.0 将之前的客户端/服务端组合改为独立客户端扩展。V1.2.0 的历史回滚资料仍保留在旧版本存档中；本仓库不携带旧 Git 历史，也不需要旧服务端插件。回滚时可重新安装已留存的 V1.2.0 客户端版本；卸载 V1.3.0 可删除其扩展目录并重启 SillyTavern。
